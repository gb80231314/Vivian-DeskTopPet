# 换形象指南

本指南说明如何把 Vivian 桌面宠物**换成另一个 Q 版形象**（其他角色、其他风格、其他配色）。换形
象不需要改任何应用代码——只需要替换素材、重跑一次精灵图构建脚本。

> 适用版本：V1.0.0 及之后

---

## 1. 你需要准备什么

### 1.1 角色素材（必备）

把一个新角色的所有静态帧画好（PNG，透明背景），每帧尺寸 **192 × 208 像素**：

| 状态        | 帧数 | 说明                                                |
|-------------|------|----------------------------------------------------|
| `idle`      | 16   | 捧花待机 — 轻微呼吸起伏                          |
| `running`   | 16   | 跑动                                                |
| `waving`    | 16   | **举臂挥手**（v1.0 起新版） — 必须能露出右臂轮廓 |
| `jumping`   | 16   | 跳跃                                                |
| `working`   | 16   | 电脑前工作                                          |
| `review`    | 16   | 皱眉审视                                            |
| `angry`     | 16   | 抱臂生气                                            |
| `wink`      | 16   | 俏皮眨眼比 V — 头部完整                           |
| `hatching`  | 16   | 蛋壳裂开（首次启动孵化）                          |
| `failed`    | 16   | **叹气** — 头胸可见，能露右侧脸颊                 |
| `walking`   | 16   | 走路                                                |
| `waiting`   | 16   | 等待                                                |

> 共 12 个状态 × 16 帧 = **192 张图**。每张图都按相同的"角色锚点"对齐（脚底 y=200，头顶 y≈10）。

> 💡 **最快起步路径**：用本项目的 `scripts/raw_assets/` 目录下的 AI 参考图作为风格引导，让设计师或
> ComfyUI/Stable Diffusion 按这套规格重新出图。所有原图生成 prompt 都附在该目录下。

### 1.2 参考眼位（重要！）

- **左眼**：`(77, 81)` — 在 192×208 帧坐标里
- **右眼**：`(114, 80)`

如果新形象的眼睛位置差异较大（±5px 以上），需要更新 `app/qpet_app.py` 顶部常量：

```python
_EYE_LEFT  = (77, 81)
_EYE_RIGHT = (114, 80)
_EYE_R  = 8    # 横向半径
_EYE_RY = 7    # 纵向半径
```

> ✏️ 修改后必须重新生成精灵图（步骤 3）让 `pet.json.eyeTracks` 自动校准。

### 1.3 语音包（可选）

如果新形象要换音色或台词风格，把音频放进 `assets/voicepacks/<新包名>/`，每个事件一个 mp3：

```
voicepacks/
└── 你的包名/
    ├── greet.mp3    # 孵化打招呼
    ├── happy.mp3    # CPU 低负载开心
    ├── neutral.mp3  # CPU 中负载平静
    ├── angry.mp3    # CPU 高负载生气
    ├── wink.mp3     # 长时间无点击俏皮提醒
    ├── failed.mp3   # 失败叹气
    └── wave.mp3     # 挥手
```

> 用户也可以把自己的语音包丢进 `%APPDATA%/QPet/voicepacks/`（Win）或
> `~/Library/Application Support/QPet/voicepacks/`（Mac），无需重新打包。

### 1.4 应用图标（可选）

- `assets/vivian.png` — 主图标（PNG，256×256 或 512×512 方形即可）
- `assets/vivian.ico` — Windows 应用图标（多尺寸：16/32/48/64/128/256）

> Mac 打包时会自动把 vivian.png 转 icns，无需单独提供。

## 2. 放置素材

把新形象的所有帧按下面命名放到一个临时文件夹（任意路径），例如 `D:/my-character/frames/`：

```
frames/
├── idle/
│   ├── 0.png
│   ├── 1.png
│   └── ... 15.png
├── running/
│   └── ...
├── waving/
│   └── ...
... (12 个文件夹，每个 16 张)
```

每个 PNG 必须是：
- 192 × 208 像素
- RGBA（透明背景）
- **角色锚点对齐**：脚底 y=200，水平居中 x=96

---

## 3. 跑构建脚本生成精灵图

修改 `scripts/build_pet_v7.py` 顶部的素材源目录常量（或用参数传入），然后执行：

```bash
cd scripts
python build_pet_v7.py
```

构建脚本会自动：

1. **肤色分割切臂**（waving 动画）— 用肤色参考色在每帧切下右臂
2. **补洞修复**（waving/failed）— flood fill 修复切臂后裙子的内部空洞
3. **举手挥臂合成**（waving）— 绕肩关节旋转 0°→132°→挥动两拍→收回
4. **叹气动画**（failed）— 吸气上挺 → 停顿 → 呼气下沉 + 卡通云雾
5. **眼睛逐帧跟踪** — 对每个动画逐帧做模板匹配，写入 `assets/pet.json` 的 `eyeTracks` 字段
6. **精灵图拼装** — 14 行（12 动画 + 2 注视占位） × 16 帧 = 224 格
7. **写 pet.json** — version、spriteVersionNumber、eyeTracks、animations

> 跑完会更新：
> - `assets/spritesheet.png` (3072×2912)
> - `assets/spritesheet.webp` (压缩版)
> - `assets/pet.json` (含眼位校准)

## 4. 验证

### 4.1 桌面查看

```bash
cd app
python qpet_app.py
```

重点检查：

- [ ] 12 种动画都能播放
- [ ] 挥手是**举臂**姿势，肩关节圆滑无突兀
- [ ] 叹气时头右侧有云雾飘出
- [ ] 眨眼眼睑**贴合**眼位（不偏离 2 像素以上）
- [ ] 观察模式（设置中开启）眼睛跟随鼠标，且**不**与眨眼冲突
- [ ] CPU 情绪联动切换正常
- [ ] 语音包能播放（设置中试听）

### 4.2 自动化截图比对（推荐）

可以做一个 Puppeteer / Playwright 脚本截图各状态做差异对比，但桌面宠物位置随机，用 ImageGrab
对窗口截图更简单：

```python
from PIL import ImageGrab
img = ImageGrab.grab(bbox=(x, y, x+W, y+H))
img.save("check_idle.png")
```

---

## 5. 重新打包

按 `docs/BUILD.md` 第 3 节执行：

```bash
# Windows
scripts/build-windows.bat

# macOS（必须在 Mac 上执行）
cd scripts && python3 build_mac.py
```

新形象的安装包会在 `release/` 目录下产出。

## 6. 清单：换形象必做事项

- [ ] 12 动画 × 16 帧 PNG，每帧 192×208 RGBA，锚点对齐
- [ ] 跑 `scripts/build_pet_v7.py` 重建精灵图
- [ ] 检查 `assets/pet.json.eyeTracks` 是否完整（80 帧每帧 score > 0.5）
- [ ] 如眼位差异大，更新 `app/qpet_app.py._EYE_LEFT/RIGHT/R/RY`
- [ ] 桌面启动验证 12 动画 + 眨眼 + 挥手 + 叹气
- [ ] 替换 `assets/vivian.png` 和 `assets/vivian.ico`（如需要）
- [ ] （可选）替换/新增语音包到 `assets/voicepacks/`
- [ ] 重新打包 Windows / Mac 安装包

---

## 7. 进阶：自定义动画清单

如果新形象要增减动画（比如把"叹气"改成"打哈欠"），需要：

1. 修改 `scripts/build_pet_v7.py` 的 `POSES` 表：
   ```python
   POSES = [
       ("idle",      0,  "奉花待机"),
       ("running",   1,  "跑动"),
       ...
   ]
   ```
2. 修改 `app/qpet_app.py` 的 `ANIMATIONS` 字典（key → row 映射）
3. 重新构建精灵图 + pet.json
4. 重新打包

> ⚠️ 增减动画会破坏向后兼容（用户的 settings.json 中动画相关键值可能错位），建议保持 12 个动画稳定，
> 新动作通过覆盖现有动画名称实现。
